# PM

[![skills.sh](https://skills.sh/b/ishanAhuja/pm)](https://skills.sh/ishanAhuja/pm)

Supervise and land the ready implementation tickets under a parent spec issue, one at a time.

## Install

```sh
npx skills add ishanAhuja/pm
```

## Use

```text
Use $pm to run and land the ready tickets under spec issue #123.
```

PM is explicit-only. It leaves the parent issue open and asks before any production deployment triggered by landing work.
